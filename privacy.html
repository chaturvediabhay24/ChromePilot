ChromePilot Privacy Policy

Updated October 14, 2026. Applies to version 0.1.5.

ChromePilot is created by Abhay Chaturvedi. Contact: chaturvediabhay24@gmail.com.

Information used for browser tasks

After you accept the in-extension disclosure and start a task, ChromePilot sends your prompts, conversation history, page text and DOM snapshots, tab titles and URLs, screenshots, and requested console or network diagnostic output to GitHub Copilot. These can contain personal, confidential, financial or other sensitive information from the pages you visit. Avoid running it on sensitive pages. Password-field values are omitted from structured snapshots, but screenshots and other page content are not guaranteed to be redacted.

Tasks can navigate pages, type, click, and change website data. Website interactions may submit data to those websites. Use Stop to stop further task actions; already completed actions and transmitted data cannot be undone by stopping.

Authentication and local storage

GitHub receives device authorization requests and authentication tokens. GitHub device-flow tokens, settings and conversation sessions are saved in Chrome extension local storage on your device, not in an encrypted credential vault. Short-lived Copilot tokens are cached in service-worker memory. GitHub and your organization's policies govern provider-side processing and retention. ChromePilot does not control provider retention.

Sharing and purpose

This build has no separate creator-operated conversation-upload backend or analytics service. Data is used to provide the browser tasks you request, not advertising or sale. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your controls

Revoke task consent in Settings to stop a run and prevent new tasks. Use the session menu to delete individual sessions. Use Settings → Delete all local data to remove saved sessions, credentials and settings and restart the extension. Signing out in one session does not delete other sessions or revoke GitHub authorization. Revoke authorization through your GitHub account settings when needed. Local deletion does not erase data already sent to providers or websites.

Permissions

Web access and scripting enable observation and predefined actions on HTTP/HTTPS pages selected for tasks. Page scripts are injected when a task needs them, rather than automatically on every page load. They may remain in an already-used tab until it is reloaded or closed. Tabs and webNavigation support tab selection and frames; activeTab supports user-invoked capture; sidePanel provides the interface; storage retains settings, consent and sessions.

Contact

Email the creator for privacy questions. Information you voluntarily send by email is received by the creator and the email provider; do not send passwords or tokens.
