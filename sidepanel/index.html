Timing

Controls how long to wait after each page-modifying action before the agent continues. Gives the page time to render dynamic content.

No Post-Action Delay

Tools checked here skip the post-action delay entirely. Read-only tools are selected by default.

DOM Snapshot Defaults

Default parameters for every get_dom_snapshot call. Controls how much of the page the agent sees per call.

Auto-Snapshot

After the selected tools execute, a DOM snapshot is automatically appended to the response. This saves a full LLM round trip — the agent sees updated page state without asking for it.

Auto-Purge

When the agent finishes (responds with text, no more tool calls), outputs from the selected tools are replaced with a placeholder in conversation history. Keeps context lean and delays hitting token limits.
